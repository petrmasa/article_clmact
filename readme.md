# CLM repository content

## Installing and running examples

* install requirements.txt (pip install -r requirements.txt)
* go to the folder with examples
* run each example by running python <file\_name>.py

## About

This repository contains replication code for the publication.

## Structure of the repository

The repository contains several folders:

* **code** -- contains full code for the replication (8 examples; see below)
* **results** - contains results of the procedure runs (8 text outputs and 7 charts)
* **pivot\_table** - contains pivot table shown as an example in introduction (note that dataset columns are reduced for performance)

## Individual tasks

* **clm\_ch4\_3\_perf\_test** -- Replication material for performance test (real number of verifications needed)
* **clm\_ch5\_1\_init\_example** -- Example of 4ft-Miner (Section 5\_1)
* **clm\_ch5\_2\_new\_measure\_with\_chart** -- Contains example of embedding CleverMiner/using own measure of interestingness and handling results (Section 5.2)
* **clm\_ch5\_3\_actplusminer\_demo** -- illustration example for Act+Miner (Section 5.3)

## Jupyter notebook

Note that the repository contains also Jupyter notebook **clm\_demo.ipynb** including all replication materials and results. Note that due to different principles used in Jupyter Notebook and python scripts, the code does not correspond 100\% to the article text as the master is the set of replication scripts. The differences are only technical, from content point of view, tasks and results are identical.
